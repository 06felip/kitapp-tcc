 KITAP — Plataforma de Leitura com Chat em Tempo Real
 
-Descrição-

O KITAP é uma plataforma web desenvolvida com o objetivo de incentivar o aumento de leitores autodeclarados no Brasil e no mundo, promovendo um ambiente digital interativo voltado à leitura.

A aplicação oferece espaços dedicados à leitura e salas específicas para livros, permitindo a interação entre usuários por meio de um sistema de chat em tempo real, tornando a experiência mais dinâmica e colaborativa.

 -Tecnologias Utilizadas-

- Frontend

HTML5,
CSS3,
JavaScript

- Backend

PHP 

- Comunicação em Tempo Real

Node.js,
WebSocket

 -Funcionalidades-

 Ambientes digitais para leitura
  
 Chat em tempo real entre usuários

 Comunicação entre frontend e backend via JavaScript

 Troca de dados dinâmica utilizando requisições HTTP
